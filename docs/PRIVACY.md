# Privacy

SafeShare 不需要账号，不上传用户选择的图片或文件到自建或第三方服务器，也不接入第三方 AI API。

照片、PDF、Word、Excel、PowerPoint 及音视频文件的元数据检查，设备可用时的照片视觉检测，用户选择的区域遮盖，文档属性清理，水印合成、重新编码和输出复检均在设备上完成。输入文件只读，应用不修改原文件。照片和支持清理的文档以新的临时副本输出；音视频仅用于读取和展示容器元数据，不生成已清理副本。应用只读取完成用户所选功能所必需的数据；文档结果页使用系统预览能力，不为界面额外提取正文。处理副本与临时水印素材写入应用缓存目录，在用户返回、操作被替换、分享完成或关闭后短暂延迟删除；应用下次启动也会清理可能遗留的净享临时文件。

诊断日志只包含固定阶段名和数值状态，不包含 URI、二维码内容、文件名、坐标、元数据原值或文档正文。

界面不会展示二维码内容或精确 GPS 数值。设备端视觉能力不可用时，应用明确列出未完成项；在人脸与二维码真机门禁完成前，商店文案不会将其声明为已验证能力。
