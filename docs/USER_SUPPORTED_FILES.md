# 净享可处理的文件类型

除系统相册里的照片/视频外，下列类型可从「文件」页或系统分享进入。

说明：**只清理元数据，不改画质/音质/正文**。原文件不会被修改，结果为沙箱中的临时副本。

## 可清理（生成安全副本）

| 类型 | 扩展名 | 会清理什么 | 备注 |
|---|---|---|---|
| Word | `.docx` `.docm` `.dotx` `.dotm` | 作者、最后修改者、公司、时间、关键词等文档属性 | 正文与附件保持原样 |
| Excel | `.xlsx` `.xlsm` `.xltx` `.xltm` | 同上 | 公式与宏包保持 |
| PowerPoint | `.pptx` `.pptm` `.potx` `.potm` `.ppsx` `.ppsm` | 同上 | 幻灯片内容保持 |
| PDF | `.pdf` | 标题、作者、主题、关键词、创建/修改程序与时间 | 可选整页文字水印；复杂 PDF 可能丢失表单/书签（非无损） |
| 视频 | `.mp4` `.mov` | 容器内位置、时间、作者等元数据 | 编码轨道复制，画质不变 |
| 音频 | `.mp3` | ID3v1 / ID3v2 / APE 标签 | 音频帧原样保留 |
| 音频 | `.m4a` | 容器元数据（remux 复制音频轨） | 音质不变 |
| 音频 | `.flac` | Vorbis Comment、内嵌封面图等 | 保留 STREAMINFO，音频帧原样 |
| 音频 | `.wav` | LIST INFO、bext、iXML 等 | 保留 `fmt`+`data`，采样原样 |

## 仅检查（不生成清理副本）

| 类型 | 原因 |
|---|---|
| `.ogg` `.opus` `.aac` `.amr` | 标签结构各不相同，尚未实现无损写回 |
| 其他未列出的音视频容器 | 同上 |

## 暂不支持

| 类型 | 说明 |
|---|---|
| **动态照片**（相册动图） | 系统限制，无法在不破坏动态效果的前提下完成清理 |
| 旧版 Office：`.doc` `.xls` `.ppt` `.dot` `.xlt` `.pps` | Office 97–2003 二进制格式，请先在电脑/WPS 另存为 `.docx` / `.xlsx` / `.pptx` |
| 加密或带数字签名的文档 | 清理会破坏加密/签名，直接拒绝 |
| `.svg` `.epub` `.zip` 等 | 当前版本未接入 |

## 使用提示

1. 清理前应用会列出检测到的隐私项，可逐项选择删除或保留。  
2. 生成后可切换「原图 / 安全副本」对比，再分享。  
3. 分享结束或退出应用后，临时副本会自动清理。  
4. 相册内的照片（JPEG / HEIC / PNG 等）请走「选择图片」或系统分享，能力以应用内支持说明为准；**动态照片除外**。
