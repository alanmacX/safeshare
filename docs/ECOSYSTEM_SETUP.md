# HarmonyOS ecosystem integration

## 产品范围

当前版本不接入小艺 Intents、App Linking，也不实现独立的附近设备发送。这些入口不会改善照片处理核心闭环，却会增加注册、审核与维护成本。

生成安全副本后仍使用系统分享面板作为通用分享出口。

## 平板与折叠屏

当前 module 已启用 `auto_rotation`。布局以窗口而非设备名称判断：小于 600 vp 为紧凑窗口，600–839 vp 为中等窗口，840 vp 及以上为展开窗口；宽高比超过 1.08 时进入横屏高度压缩策略。首页、功能入口和扫描页均限制内容宽度，横屏会缩短预览、泡泡、标题间距和设置面板上下留白，避免 16:10 平板及低高度分屏窗口溢出。

粗略覆盖的屏幕形态：

- 直板手机与折叠外屏：约 20:9，通常使用紧凑单列。
- Mate X6 展开内屏：2440 × 2240，接近方形，使用展开单列并保留宽边距。
- Pura X 阔折叠内屏与 MatePad Mini：约 16:10，横屏启用高度压缩，竖屏保持大预览。
- 分屏与自由窗口：只根据实时窗口 vp 重新落入断点，不假设物理设备类型。

仍需在 MatePad Mini 验证横竖屏、分屏、自由窗口、大字体和键鼠/拖放。只有结果信息量足以支撑时再引入双栏；首页和单一导入入口不使用永久侧栏。
