# AppGallery Review Notes

## 核心功能

应用主页为两个底部标签页：「照片」与「文件」。照片页选择照片后进入同一结果页，可同时启用隐私清理（元数据删除/替换、人脸与二维码遮盖）与用途水印，预览安全副本并继续分享；文件页按文件类型自动路由到对应工具（PDF / Word / Excel / PPT / 音视频）。标题栏随所在标签页显示对应标题。

用户可在图库等应用的系统分享面板选择"净享"，查看照片中可能暴露位置、时间、设备或身份的信息，选择需要遮盖的视觉区域，预览安全副本并继续分享。也可在应用内通过系统图片选择器进入同一流程。

除照片外，净享还为每类文件提供独立工具：

- **PDF 文档检查**：读取 PDF 元数据（作者、标题、主题、关键词、创建/生成程序、创建/修改时间），生成清除元数据后的 PDF 副本。
- **Word / Excel / PPT 检查**：读取并清除 Office 文档属性中的作者、最后修改者、公司、经理、关键词、主题、备注、时间与自定义属性，生成清理后的文档副本。
- **音视频隐私检查**：读取媒体文件中的位置、录制时间、作者等元数据并如实展示。HarmonyOS 未提供本地去除媒体容器元数据的接口，因此不生成"已清理"副本，只报告风险并建议替代方案。

## 数据处理

- 不需要账号，不使用自建服务器或云数据库。
- 输入文件只读，不修改原图或原文件。
- 输出位于应用缓存沙箱，并在分享结束后清理。
- 图片：只解码可见像素、按用户选择遮盖真实检测区域并创建新文件，不复制源元数据块。
- PDF：使用系统 PDF Kit 读取元数据；在沙箱副本中仅对可确定的 Info 字段做等长清空，保持交叉引用偏移不变；输出副本经 PDF Kit 复检，无法确定解析时不生成结果。
- Word/Excel/PPT：仅重写文档属性部分的 XML，文档正文按原始字节保留；输出副本经复检确认属性已清除。
- 音视频：只读取元数据，不生成副本、不修改文件。
- 元数据与本次实际遮盖的人脸/二维码类别会在展示分享面板前针对性复检；复检不通过时不会分享。

## 使用的 Kit

- Share Kit：解析分享内容、显示系统分享面板。
- Image Kit：创建 ImageSource、读取图片属性、解码 PixelMap、ImagePacker 编码。
- Media Library Kit：PhotoViewPicker 权限免打扰选图。
- Core File Kit：缓存文件创建、URI 转换与删除；DocumentViewPicker 选择文档/音视频。
- Core Vision Kit：人脸检测；设备不支持时明确降级。
- Scan Kit：二维码和条码区域检测，不展示码内容。
- PDF Kit：读取与重写 PDF 文档（元数据扫描与清理副本）。
- Media Kit（AVMetadataExtractor）：读取音视频容器元数据（只读）。
- zlib（系统库）：Office 文档 ZIP 容器中 deflate 条目的解压。

## 权限

应用不申请任何用户敏感权限。图片选择走系统 PhotoViewPicker，文档/音视频选择走
DocumentViewPicker，均由用户主动选择后由系统授予临时读取授权。

## 审核验证步骤

1. 在图库选择一张带 GPS/设备信息的 JPEG。
2. 点击分享并选择“净享”。
3. 展示实际发现的元数据风险，以及设备已完成/未完成的视觉检查；没有检测结果时不会制造示例结果。
4. 逐项选择元数据删除、保留或替换；如果测试设备实际返回了视觉区域，可选择是否遮盖，然后点击“生成安全副本”。
5. 切换原图/安全副本预览，点击“分享副本”。
6. 对比原图元数据仍存在，安全副本元数据已移除。
7. 在文件管理分享一个 docx/xlsx/pptx 给“净享”，确认显示作者/公司等文档属性，生成副本后在 Office 应用中可正常打开且属性已清除。
8. 分享一个 PDF 给“净享”，确认显示元数据，副本在 PDF 预览中可正常打开。
9. 分享一个带位置信息的视频或音频，确认显示位置/时间风险，并如实提示该类型暂不支持本地生成清理副本。
